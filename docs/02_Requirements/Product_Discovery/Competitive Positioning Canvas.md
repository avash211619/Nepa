Competitive Positioning Canvas — Nepa (Project Nebula)

Positioning statement
For content creators, developers, and small businesses who need fast, private, and SEO‑friendly image optimization, Nepa is the workflow platform that offers a single upload → multi‑step optimization pipeline with privacy‑first defaults and developer parity. Unlike TinyPNG (tool) or Cloudinary (infrastructure), Nepa focuses on end‑user workflows first, then scales to APIs and enterprise.

Canvas (4 quadrants)
- Target users: Students, Bloggers, E‑commerce sellers, Developers, Designers, Agencies
- Key problems solved: Multiple tool hops, unclear format choice, privacy concerns, batch automation gaps
- Alternatives: TinyPNG, iLoveIMG, Squoosh, FreeConvert (consumer features); Cloudinary, ImageKit, Imgix (infrastructure)
- Differentiators: Single upload workflow; privacy‑by‑default; SEO & content‑first landing pages; reproducible presets for future API parity

Competitor snapshot (short)
- TinyPNG: Best‑in‑class compression quality, plugin ecosystem. Gap: workflow chaining, bulk automation for merchants.
- iLoveIMG/ImageResizer: SEO traffic & many consumers. Gap: shallow features, ad‑driven UX.
- Squoosh: Best privacy & codec coverage (client‑side). Gap: no batch, no automation.
- Cloudinary/ImageKit/Imgix: Enterprise features, CDN + transformations. Gap: complexity & price for SMBs; less consumer friendly.

Positioning map (verbal)
- X axis: Ease of use (left=low, right=high)
- Y axis: Enterprise feature set (bottom=consumer, top=enterprise)
- Nepa target: high ease of use + mid enterprise capability (start consumer + scale to API)

Top 3 Differentiators (short)
1. Workflow Platform: One upload, multiple outputs, action recommendations.  
2. Privacy & Client Processing: Local processing when possible; clear, minimal retention policy.  
3. SEO & UX‑First Product: Tool pages that convert users into multi‑step flows (increase page depth and retention).

Go / No‑Go
GO — Competitive canvas shows a realistic gap between consumer utilities and enterprise platforms where Nepa can own the workflow experience and scale later to APIs and enterprise.
