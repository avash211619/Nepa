UX Brief — Core Workflow (MVP)

Objective
Design an intuitive, mobile-first experience for the core workflow: upload → analyze → recommend → optimize → preview → download.

Key UX principles
- One upload, multiple actions. Keep friction minimal.
- Privacy-first choices clear and discoverable.
- Provide defaults with sensible presets and one-click actions.
- Visual preview with comparison slider is central to trust and conversions.

Primary screens
1. Landing / Tool Hub
   - Clear hero CTA: "Upload an image — Get it web-ready"
   - Quick links to common tasks (HEIC → WebP, Compress PNG, Responsive images)
2. Upload / Analysis
   - Drag & drop, browse, paste, camera (mobile)
   - Immediate attribute display (format, size, dimensions)
3. Recommendation & Presets
   - Suggested preset (Article, Social, Marketplace) with short rationale
   - Manual controls hidden behind "Advanced" for power users
4. Processing & Preview
   - Progress indicator for server-side jobs
   - Side-by-side or slider comparison with size delta
5. Download / Next Steps
   - Download optimized file
   - Related tools widget (remove EXIF, batch optimizer)

Accessibility
- WCAG 2.1 AA target
- Keyboard focus for upload controls
- Proper ARIA for progress and alerts

Deliverables
- Low-fidelity wireframes (inline in Wireframes.md)
- Component inventory for dev handoff
- Interaction spec for upload and preview flows
